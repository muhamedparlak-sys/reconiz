# RecOniz · Amphora Recognizer

RecOniz, tek bir fotoğraftan bir amphoranın tipini belirlemeye yardımcı olmak için geliştirilmiş, tarayıcıda çalışan bir tanıma aracıdır.
RecOniz is a browser-based tool that helps identify the type of an amphora from a single photograph.

**Uygulama / App:** https://reconiz.org

RecOniz, Hakan Öniz’in danışmanlığında Muhammed Parlak tarafından geliştirildi (2026).
Tip adları, tarihler ve çizimler Hakan Öniz ve ekibinin “Mediterranean Amphorae” şemasından alınmıştır (Günay Dönmez, Ercan Soydan, Ergün Şimşek, Elif Nur Dönmez, Jack Torode, Köksal Özdemir, Pearl Norman Brown). Diğer kaynaklar ve atıflar uygulamanın “Kaynakça” bölümündedir.

Analizler tamamen kullanıcının cihazında yapılır; fotoğraflar hiçbir yere gönderilmez.
